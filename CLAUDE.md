# Games

The home page for https://games.shauna.digital. Read `README.md`: it explains the hosting, the domain, how games are mounted under a path, and how to add one. Then `_docs/PROJECT_STATUS.md` for what is live, the decisions and why, and what is next.

- Plain static site: `index.html`, `vercel.json`, `og.png` and `fonts/`. No build step.
- Fonts are self-hosted subsets in `fonts/` (about 13 KB for all three (Momo Signature removed with the captions 2026-10-16; Fredoka, Press Start 2P and Shantell Sans removed 2026-10-17 when the card titles became images), down from about 219 KB from Google Fonts, 2026-10-11). Each file holds only the characters the page shows, so after changing ANY visible text (tagline, card title, footer) add it to `tools/subset-fonts.py`, run `python3 tools/subset-fonts.py`, and paste the printed `@font-face` rules over the block at the top of the `<style>` in `index.html`. A missing character silently falls back to a system font.
- Repository `shaunagits/games`, Vercel project `games`, team `shaunagits-projects`. Every push to `main` deploys to production.
- Current design (updated 2026-10-11): title "Midnights" (Syne), neon tagline "Little games for late nights." that flickers, straight (untilted) polaroid game cards over an animated "gooey blobs" background, teal polaroid tab icon. Each card's photo is the game's own logo over its own background, one 600 by 600 webp per game in `img/` (`<path>-card.webp`), all Shauna's art (TropiChop 2026-10-16, the other three 2026-10-17).
- Background (Shauna, 2026-10-11, "keep it just the way it is for now"): pink, orange and violet blobs ("Sunset lava") on deep plum, drawn as metaballs on a low-resolution canvas (one canvas pixel per 3 screen pixels, 4 above 1600px wide) at about 30 frames a second, with an animated film grain on top. A smaller blob follows the cursor or finger, stretches as it moves and sheds droplets that rejoin it. Hovering a card (or, on touch screens, the card nearest the middle of the screen while scrolling) tints the blobs toward that game's color. Tapping empty space splits the nearest blob in two and the halves rejoin. Scrolling makes the blobs drift. With reduced motion it draws one still frame. All of it is the `.bg` styles and the script at the end of `index.html`.
- Cards (updated 2026-10-16): newest game first with a pink "New" sticker (move it when a new game lands). No captions (Shauna removed all card teasers, 2026-10-16): each polaroid is the photo plus a blank 52px bottom margin. The game name is in each link's aria-label ("TropiChop, new game", "Saltwhisker", and so on). No "Play" button: the whole card is the link (Shauna removed the Play pills, 2026-10-11). A "Still developing." polaroid (slow fog) for the next game exists but is hidden in an HTML comment (Shauna, 2026-10-11); restore it to tease a game.
- Footer, on a soft dark band so the light text passes contrast: "Made by Shauna." (links to https://shauna.dev) plus "By day I build software for growing businesses at shauna.digital" (links to https://shauna.digital).
- The page description is "Little games for late nights. Made by Shauna." Link previews use og:title "Midnights: little games for late nights" and `og.png` (1200 by 630, the three newest cards over the blobs). Regenerate `og.png` when the cards change; the recipe is in `_docs/PROJECT_STATUS.md`.
- Vercel builds one project at a time for this account; a stuck build on another project (for example faf-app) blocks deploys here. Check the queue before assuming a push failed.
- No em dashes in any text. No AI or assistant credit in code, commits, or docs.
- All artwork is original. No artist names, logos, album artwork, or lyrics.
