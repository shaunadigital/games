# Games

The home page for https://games.shauna.digital. Read `README.md`: it explains the hosting, the domain, how games are mounted under a path, and how to add one. Then `_docs/PROJECT_STATUS.md` for what is live, the decisions and why, and what is next.

- Plain static site: `index.html`, `vercel.json`, `og.png` and `fonts/`. No build step.
- Fonts are self-hosted subsets in `fonts/` (about 13 KB for all three (Momo Signature removed with the captions 2026-10-16; Fredoka, Press Start 2P and Shantell Sans removed 2026-10-17 when the card titles became images), down from about 219 KB from Google Fonts, 2026-10-11). Each file holds only the characters the page shows, so after changing ANY visible text (tagline, card title, footer) add it to `tools/subset-fonts.py`, run `python3 tools/subset-fonts.py`, and paste the printed `@font-face` rules over the block at the top of the `<style>` in `index.html`. A missing character silently falls back to a system font.
- Repository `shaunagits/games`, Vercel project `games`, team `shaunagits-projects`. Every push to `main` deploys to production.
- Current design (updated 2026-10-17): title "Midnights" (Syne), neon tagline "Little games for late nights." that flickers, straight (untilted) polaroid game cards clipped to strings of lights on a cork wall, teal polaroid tab icon. Each card's photo is the game's own logo over its own background, one 600 by 600 webp per game in `img/` (`<path>-card.webp`), all Shauna's art (TropiChop 2026-10-16, the other three 2026-10-17).
- Background (Shauna, 2026-10-17): her cork wall at night (`img/wall.webp`, fixed behind the page) with the polaroids clipped to strings of lights. The strings, bulbs and wooden clips are drawn by the script at the end of `index.html`, one string per row of cards, redrawn on resize. Bulbs are vintage glass (colored glass, white-hot core, ridged metal base, soft halo, a pool of light on the cork) on a twisted wire with a shadow; the clips are wooden clothespins with a steel spring (an inline SVG in `.card::before`). Bulbs twinkle gently and one flickers every few seconds; the ones near a hovered, focused or centered card glow in that game's color (`TINT`), rippling out from that card. On phones the swipe area has 60px of headroom so the glow is not clipped. Cards swing on hover and swing before the game opens on a tap. Layout: 4 across from 1060px, 2 by 2 below that, and under 700px one clothesline you swipe sideways with dots below (a tap on a side card centers it first). Reduced motion: no twinkle, no swing, no smooth scroll.
- Cards (updated 2026-10-16): newest game first with a pink "New" sticker (move it when a new game lands). No captions (Shauna removed all card teasers, 2026-10-16): each polaroid is the photo plus a blank 52px bottom margin. The game name is in each link's aria-label ("TropiChop, new game", "Saltwhisker", and so on). No "Play" button: the whole card is the link (Shauna removed the Play pills, 2026-10-11). A "Still developing." polaroid (slow fog) for the next game exists but is hidden in an HTML comment (Shauna, 2026-10-11); restore it to tease a game.
- Footer, on a soft dark band so the light text passes contrast: "Made by Shauna." (links to https://shauna.dev) plus "I design and build software. See more of my work at shauna.digital" (links to https://shauna.digital). Changed 2026-10-18 to be evergreen, not tied to one business.
- The page description is "Little games for late nights. Made by Shauna." Link previews use og:title "Midnights: little games for late nights" and `og.png` (1200 by 630, all four cards on the wall). Regenerate `og.png` when the cards change; the recipe is in `_docs/PROJECT_STATUS.md`.
